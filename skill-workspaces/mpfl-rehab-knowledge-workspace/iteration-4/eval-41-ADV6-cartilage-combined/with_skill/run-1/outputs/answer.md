PICO: Combined surgery (MPFLR with a cartilage restoration procedure), COMB. Age group not stated. Weeks since surgery not stated. Question: can the app use the P2 phase table with weight-bearing as tolerated?

## Answer

No. The app must not use the P2 phase table or weight-bearing as tolerated for this patient. A surgeon protocol is required. The app must not set a default for weight-bearing, brace or phase.

P2 does not cover this surgery. P2 excludes it. P2 is an isolated soft-tissue guideline for ages 8 to 25.

## Reading

- Weight-bearing as tolerated is a common practice for isolated MPFLR only (S10, R3, ISO). It is not a consensus (N1). It is not a default.
- The S10 numbers for delayed or non weight bearing come from TTO protocols, not from cartilage protocols. They are BORROWED for a cartilage procedure. The knowledge base has no weight-bearing value for a cartilage procedure.
- S1 and P1 both say to change the protocol for a chondral procedure or to follow the most conservative guideline.
- The knowledge base does not say which cartilage procedure was done. Different procedures can have different loading limits. This is not in the knowledge base. A surgeon protocol is the kind of source that can answer.

## Disagreements

- Weight-bearing in isolated MPFLR: WBAT in 66 percent of protocols (S10), partial weight-bearing in 26 percent, none or delayed in 6 percent. N1 says there is no consensus. The conservative value for this patient is the restriction that the surgeon sets. Values are not averaged.
- N5 (RCT, TTO plus MPFLR, N=50) says rapid rehabilitation "appears to be safe and effective". It supports the choice of the surgeon. It does not support an isolated default for a cartilage patient (citation-audit.md section 4.7).

## Ask your surgeon

- Weight-bearing status and crutch use, and the date it changes.
- Brace use: yes or no, locked or open, and the end date.
- The flexion limit and the start date of motion.
- Maximum squat depth and the load limit.
- Permission to start each new phase. The P2 criteria are a reference only.
- Which cartilage procedure was done, and the loading limits that come from it.

## Gaps

- Weight-bearing after MPFLR with a cartilage procedure: NONE. The literature gives practice counts for TTO protocols (S10) and a general statement that concurrent procedures change the protocol (S1, P1).
- A validated protocol after MPFLR: NONE. S1: "no validated rehabilitation protocols are established following MPFL reconstruction".
- A phase table for a combined procedure in the knowledge base: NONE.

Note: the app shows "ask your surgeon" for these fields. It does not choose a phase, a limit, a load or a date.
