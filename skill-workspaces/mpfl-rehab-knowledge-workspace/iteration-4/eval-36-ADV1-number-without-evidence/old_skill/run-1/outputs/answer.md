# Heel slide: seconds per rep and sessions per day

Not in the knowledge base. I cannot give an evidence-based number for either field.

## Seconds per rep
- Source status: NONE. No MPFLR source gives a tempo (`research/rehab-rules.md`, row "Tempo (seconds per rep)").
- The only value in the project is "at least 2 seconds for one rep". It is a PROPOSAL start value (`research/ux-flow.md` section 7.1, plan T9b). It is not evidence. It needs clinician review before use.

## Sessions per day
- Source status: NONE. No guideline or review gives an exercise frequency after MPFLR (`research/rehab-rules.md`, row "Frequency"). The only frequency in the sources is for ice (NHS Lothian, 2 hourly), not for exercise.

## What the sources do give for the heel slide
- The heel slide is allowed in phase 1 (S1 Hsu 2025, LoE 5, clinical commentary. P3 NHS Lothian 2022. P1 HSS, revised 2024). Evidence: CONSENSUS (low).
- Range, not tempo: start 0 to 30 degrees in weeks 1 to 2, then add 20 to 30 degrees a week (S1, `research/clinical.md` section 4). Full flexion is reported at 4 to 12 weeks.
- The range ceiling comes from the surgeon (`research/clinical.md` section 9, item 1).

## For the protocol table
Do not enter a number from memory. Use these field values:
- Seconds per rep: "Ask your surgeon". Or a clinician-set value. A PROPOSAL of 2 seconds can show as a start value with the label PROPOSAL.
- Sessions per day: "Ask your surgeon".

The knowledge base can answer this only if a source is added. A source that can answer it is a clinical protocol from the care team or a trial of exercise dose after MPFLR. Send the link and it can be opened and recorded. This text supports a clinician. It does not set a protocol for a patient.
