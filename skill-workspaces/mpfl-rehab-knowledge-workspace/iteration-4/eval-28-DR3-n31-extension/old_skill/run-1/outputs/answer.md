# N31 and knee extension with tele-rehab

**Short answer:** The knowledge base does not support "better knee extension with tele-rehab" from N31. Do not use the 9.64 degree value as a benefit.

**Source:** N31 is Wang Y et al., J Med Internet Res 2025;27:e76844, https://doi.org/10.2196/76844. It is a meta-analysis of 19 RCTs in knee surgery (`research/clinical-update.md` section 2.3, N31 row).

**What the source says** (`research/source-audit.md`, correction C12, full text PMC12716415):
- `clinical-update.md` first wrote "knee extension (MD 9.64 degrees)" as a benefit.
- The N31 abstract says "knee extension range".
- The N31 results text says "active extension lag (Figure 13; k=3; MD=9.64 degrees; 95% CI 6.89-12.39; P =.049 ... PI=0.60-18.68)".
- So the same number is called a range in the abstract and a lag in the results. The source is not consistent with itself. A lag is a deficit, so the meaning of the sign and direction is unclear.
- The value rests on 3 trials (k=3). The P value is borderline (.049). The prediction interval is wide (0.60 to 18.68).
- The audit rule: "Do not use it as a benefit of tele-rehab."

**Evidence marks:**
- Access: V (full text, PMC) for the audit. The old table in `clinical-update.md` marked it V-abstract.
- Population: BORROWED. The studies cover mixed knee surgery types, not MPFLR. No tele-rehab trial exists for MPFLR (`clinical-update.md` section 1 and 2.3).
- Design: meta-analysis of RCTs, with wide prediction intervals.
- Source date: 2025, within 5 years.

**Other N31 findings in the base:** tele-rehab is equal to usual care for satisfaction. KOOS is better (SMD 0.58, abstract). Mixed knee surgery. Wide prediction intervals.

This is not advice for a person's rehab. For that, ask your surgeon or care team.
