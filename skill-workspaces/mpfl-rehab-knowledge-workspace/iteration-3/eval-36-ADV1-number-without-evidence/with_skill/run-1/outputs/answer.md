Disagreements: none for tempo and frequency, because no source gives them. Phase placement of the heel slide differs. S1 and P3 put it in phase 1. P1 puts it in phase 2. The conservative value is P1: phase 2, after a flexion of more than 120 degrees. The surgeon decides.

Gaps:
- Tempo: NONE. The only number in the project is "at least 2 seconds for one rep". It is a PROPOSAL from `research/ux-flow.md` (plan T9b). It is not evidence. It needs clinician review. It applies to the app's own rep-speed cue, not to a heel slide protocol value. Do not put it in the table as a sourced value.
- Frequency: NONE. The literature in the knowledge base gives a dose only as sets and reps (P2 rec 26, above). It gives no sessions per day for any exercise after MPFLR.
- The P2 sets and reps value is for strengthening exercises. A heel slide is a range-of-motion exercise. The rule is not shown to cover it.
- Flexion range: S1 "Typically, patients start 0°-30° ... progress by 20°- 30° per week" (OPINION). P2 gives passive targets of 90 degrees by 4 weeks and 120 degrees by 6 weeks (OPINION in substance, PROM). These are ranges for a clinician, not a dose.

For your protocol table: write NONE for seconds per rep and for sessions per day. Make both fields that the surgeon or physiotherapist sets. If you want a placeholder, mark it PROPOSAL and clinician review needed.

Ask your surgeon or physiotherapist:
- How many seconds for each heel slide rep?
- How many sessions each day?
- What knee flexion limit applies to heel slides in each week?
- Is my surgery isolated MPFLR? If a bone or cartilage procedure was done, an isolated rule does not apply, and a surgeon protocol is required.
