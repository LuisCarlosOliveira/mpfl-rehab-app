I cannot apply the P2 phase table with weight-bearing as tolerated (WBAT) to this patient. The reason is the combined surgery.

**Why the P2 table does not fit**
- P2 is the Cincinnati Children's guideline (EBCG 46) for isolated patellar instability. The project knowledge base notes that it excludes realignment surgery. It does not cover MPFLR with a cartilage restoration procedure. (research/rehab-rules.md, sources table and section 1.)
- P2 gives phase goals but no week bands. Almost all its items are consensus, evidence level 5.
- The knowledge base marks this case as COMB (MPFLR with a bone or cartilage procedure). The rule for COMB is: do not apply an isolated protocol, and require a surgeon protocol. (research/rehab-rules.md, "Combined surgery" row.)
- S1 says weight-bearing is usually not limited after isolated MPFLR. It also says weight-bearing changes if a concurrent procedure is done, and it names chondral restoration. This is opinion-level evidence (S1, OPINION). It tells us the status can change. It does not give a new status.
- The WBAT practice figures (66 percent of protocols in S10, 65 percent in R3) come from isolated MPFLR protocols. They do not carry over to cartilage work.
- For weight-bearing and brace, the research found no consensus even for isolated MPFLR (N1). Only retrospective data compare options.
- Cartilage restoration is a known gap. If a protocol for isolated MPFLR is applied to combined surgery, the knee can be overloaded (research/clinical-update.md, section 6, item 2).

**What I can do**
- I cannot set weight-bearing to "as tolerated" for this patient. The weight-bearing status, the crutch use, the brace and the range-of-motion limits depend on the cartilage procedure. The surgeon must set them. Cartilage procedures often have a protected period, but the knowledge base has no source with numbers for this, so I do not give any.
- If the surgeon has already written a protocol that allows WBAT, enter it as the surgeon's value. The app then uses it as that protocol's value, not as a P2 value. I would need that protocol, or the surgeon's limits, to continue.
- You can use the P2 phase goals (for example pain, effusion, extension, flexion and straight leg raise targets) only as a reference. They are not a prescription for this patient. The surgeon must give permission to move to each phase.
- The app intake already handles this. In question I2, "cartilage repair" is not "MPFL reconstruction only". It leads to referral R2, and the app does not generate an isolated protocol (docs/protocol-generator-design.md).

1. The surgeon's written protocol or restrictions for this patient: weight-bearing status and dates, brace, flexion limit, and the criteria for each phase.
2. The type and site of the cartilage procedure, and the date of surgery. The surgeon holds this information.

Until then, I will not generate phase content with a WBAT status. Please contact the surgical team for the restrictions.
