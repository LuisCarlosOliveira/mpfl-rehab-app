## Traps

- No validated RTS battery exists after MPFLR (S1, N4, S6). Do not write "validated".
- Thresholds disagree: 85 percent (P2, ISAKOS 2013), 90 percent (S1, ME1), 95 percent (P1, P4 from the base). Show each value with its source. Name the conservative value, which is 90 percent or more. Never average.
- The ISAKOS 2013 list is read second-hand through ME1 (Table 1). Say so. The audit found that Table 1 has 10 rows and the knowledge base quotes only 6. The primary ISAKOS document was not found.
- ME1 itself says that "no clear criteria can be as yet endorsed".
- The P3 hop rule is: two functional hop tests of more than 90 percent of the unaffected limb.
- The run-start rule of S1 comes from an ACL review (C3). It is BORROWED. P3 gives 90 percent strength before running. S1 gives 70 percent. Name the conservative value.
- S6 and S21 are mixed populations (C9, C10). N20 includes TTO patients. Say so when you use them.
- The MPFL-RSI cutoff of 56 is not validated for MPFLR. S21 reports an ACL-RSI value in a mixed population.
- Time to RTS is descriptive (about 6 to 8 months). It is not a target.
- The app cannot measure strength LSI, hop tests, Y-Balance, gait or effusion grade. A webcam value is "movement symmetry". Never write "LSI" for it.

## Format and refusals

Follow the output format and the refusal rules of `../SKILL.md`. In short:
- Each number has a source id, a class (CONSENSUS, REVIEW, STUDY, OPINION or NONE) and VERIFIED or UNVERIFIED.
- If no file gives a number, write NONE and say what the literature says instead. Never invent one.
- An unread source is UNVERIFIED and cannot support an app rule. A level 5 item of a guideline is OPINION in substance.
- A row that `research/citation-audit.md` marks WRONG or NOT READABLE is not usable. For a PARAPHRASED row, use the true wording of the audit.
