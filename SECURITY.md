# Security policy

This app is a research and evaluation prototype. It is not a medical device.

## Report a vulnerability

Use the GitHub button "Report a vulnerability" in the Security tab of this repository. This starts a private report. Do not open a public issue for a vulnerability.

A report must hold:

- The steps to repeat the problem.
- The file or screen that is affected.
- The result that you expect and the result that you see.
- The impact, as you understand it.

The owner will answer when possible.

## Scope

- In scope: the code in `app/`, including the build and check scripts.
- Out of scope: clinical content, such as a limit, a cue text or a plan value. Report it as a normal issue.
- Out of scope: the pose model files and the packages that the app uses. Report a problem there to the upstream project.

## Supported versions

Only the latest commit on `master` is supported.
